## Install

[Download the DMG installer](https://github.com/maxibenner/exec/releases/download/v0.1.3/Exec-macOS-arm64.dmg), open it, and drag **Exec** into **Applications**.

Requires **macOS 14 or later on Apple Silicon**. Existing installations can update through **Settings → Updates → Check for Updates…**. The ZIP is for Sparkle in-app updates; use the DMG for manual installation. SHA-256 checksums are included for both downloads.
