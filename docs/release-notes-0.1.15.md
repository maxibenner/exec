## Features
- The Mac sidebar shows a blue unread badge when a reply finishes in another session. Open that session to clear the badge.

## Fixes
- On Mac, queued messages keep your reading position when they send. Only an immediate send moves the new message to the top of the chat view.
- Sidebar rows now animate when you drag sessions into a new order, while respecting Reduce Motion.
- Aligned the attachment remove buttons and stopped queued-message cancel buttons from flashing as messages send.

## Updates
- Queued messages use the tool-call background and a dark gray approval-style outline, so they’re easier to distinguish from sent messages.
- File-edit approval prompts show the target path and a compact, scrollable diff with line numbers. The Deny button uses neutral styling.
- Simplified the pairing QR code dialog and made the clipboard action clearer.

## iOS companion (next app update)
- Queued messages appear in their own bubbles above the composer, with matching Mac styling and a cancel button when available.
- When a queued message sends, the chat keeps your reading position. Immediate sends still move the new message to the top of the chat view.
