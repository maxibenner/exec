# Pinned highlight queries

These unmodified upstream queries match the exact grammar versions in Package.swift.
JavaScript/JSX and TypeScript/TSX compose the JavaScript base, JSX, and TypeScript queries; C++ composes the C and C++ queries.
Only this ExecTranscript resource bundle is read at runtime; dependency query bundles are not needed.
Adjacent license files retain each upstream license.
